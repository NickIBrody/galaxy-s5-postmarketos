# postmarketOS на Samsung Galaxy S5 Duos (SM-G900FD)

Готовые образы, скрипты прошивки и всё, что нужно после установки, чтобы телефон
стал пригоден к жизни: зарядка, модем, звонки и SMS из терминала, мобильный интернет.

Собрано и отлажено вживую на одном аппарате. Подходит для **SM-G900F / SM-G900FD**
(кодовое имя `samsung-klte`, вариант ядра `klte`).

> Подробная инструкция, разбор всех проблем и объяснение костылей —
> в **[docs/podrobno.md](docs/podrobno.md)**. Здесь — короткая версия для тех,
> кто просто хочет прошить.

## Что работает, а что нет

| | |
|---|---|
| Система, интерфейс phosh | ✅ |
| Wi-Fi, Bluetooth, SSH по USB-кабелю | ✅ |
| **Зарядка батареи** | ✅ но только скриптом, драйвера в ядре нет |
| Модем, регистрация в сети | ✅ после ручной активации SIM-слота |
| Звонки — сам вызов, SMS, мобильный интернет | ✅ |
| **Голос в звонке (динамик и микрофон)** | ❌ **невозможно**, см. подробную инструкцию |
| Камера, второй слот SIM, любой звук | ❌ |

Если нужен телефон, по которому можно **разговаривать** — эта прошивка вам не подходит.
Ставьте LineageOS. Здесь получается карманный Linux, а не телефон.

## Что понадобится

- Компьютер с Windows
- Кабель microUSB
- Заряд телефона от 50%
- Файлы из раздела **[Releases](../../releases)** — там лежит всё разом

⚠️ **Прошивка стирает Android и все данные.**

## Прошивка за четыре шага

### 1. Драйверы и Odin

Установите `SAMSUNG_USB_Driver_v1.9.0.0.exe`, распакуйте `Odin3_v3.14.4.zip`
и `platform-tools-windows.zip` в папку `C:\pmos`.

### 2. Загрузчик lk2nd через Odin

Выключите телефон, зажмите **Vol Down + Home + Power**, затем Vol Up — это режим Download.
В Odin вкладка **AP** → файл `lk2nd-odin.tar` → **Start**. Больше ничего не менять.

Телефон перезагрузится в меню lk2nd.

### 3. Система через fastboot

Распакуйте `pmos-samsung-klte-v26.06-phosh.zip` в `C:\pmos`, подключите телефон
и запустите `flash.bat`. Займёт минут пять.

Если `fastboot` не видит телефон — это известная беда Windows,
лечится за минуту, см. [подробную инструкцию](docs/podrobno.md#fastboot-не-видит-телефон).

### 4. Первая загрузка

Первый запуск идёт долго, несколько минут. Пароль пользователя — `147147`,
**смените его сразу** командой `passwd`.

Подключите телефон кабелем к компьютеру — появится сеть, и телефон будет доступен по SSH:

```
ssh user@172.16.42.1
```

Этот доступ работает всегда, даже если графика не поднялась. Это ваша страховка.

## После установки

Всё дальнейшее делается по SSH. Интернет на телефоне нужен — подключите Wi-Fi:

```sh
sudo nmcli device wifi connect ИМЯ_СЕТИ password ПАРОЛЬ
```

**Зарядка** (без этого телефон не заряжается вообще):

```sh
curl -sL https://raw.githubusercontent.com/NickIBrody/galaxy-s5-postmarketos/main/scripts/chargectl.py -o /tmp/chargectl.py
sudo python3 /tmp/chargectl.py install
```

**Модем, звонки, SMS, интернет:**

```sh
curl -sL https://raw.githubusercontent.com/NickIBrody/galaxy-s5-postmarketos/main/scripts/phone-setup.sh -o /tmp/phone-setup.sh
sudo sh /tmp/phone-setup.sh
sudo reboot
```

**Чтобы не тормозило** (2 ГБ ОЗУ, видеочип 2013 года):

```sh
curl -sL https://raw.githubusercontent.com/NickIBrody/galaxy-s5-postmarketos/main/scripts/lighten.sh -o /tmp/lighten.sh
sudo sh /tmp/lighten.sh
```

## Команды, которые появятся

```sh
contact add мама +79001234567    # записная книжка

chargectl.py status              # что с зарядкой прямо сейчас
doctor.sh                        # починить пропавшую сотовую сеть
```

## Файлы репозитория

| Папка | Что внутри |
|---|---|
| `images/` | загрузчик lk2nd и `boot.img` |
| `windows/` | `flash.bat` — прошивка одним запуском |
| `scripts/` | зарядка, модем, звонки, ускорение системы |
| `scripts/ui/` | поворот экрана, терминальный режим, обход мёртвой зоны экрана |
| `docs/` | подробная инструкция и разбор всех проблем |
